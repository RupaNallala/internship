Python Exception Handling Assignments
======================================

80 questions from the uploaded assignment PDF are provided as separate .py files.
The programs are written at a beginner-friendly level and use example names such as
Rupa, Sweety, Mahi, Latha and Sri where student/name examples are needed.

Folder structure:
- Level_1_Basic_Exception_Handling: Q1-Q10
- Level_2_Try_Except_Else_Finally: Q11-Q20
- Level_3_Multiple_Exceptions: Q21-Q30
- Level_4_Raising_Exceptions: Q31-Q40
- Level_5_Custom_Exceptions: Q41-Q50
- Level_6_Exception_Handling_with_Functions: Q51-Q60
- Level_7_Exception_Handling_with_OOP: Q61-Q70
- Mini_Project_Assignments: Q71-Q80

Run any file from Command Prompt:
py Q01_Exception_Handling.py

Some file-related questions expect a file such as student.txt to exist in the
same working folder. The database question uses Python's built-in sqlite3 module,
so no external database installation is required.
